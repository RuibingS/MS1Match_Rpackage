# Annotate peaks

S4 generic for running peak annotation. Methods are provided for:

- [PeakAnnotationFromLibraryMatch](https://ruibings.github.io/MS1Match_Rpackage/reference/PeakAnnotationFromLibraryMatch-class.md):
  annotation of precomputed library matches

## Usage

``` r
annotateLibMatch(object, cutoff_MH = FALSE, ...)
```

## Arguments

- object:

  Object to annotate.

- ...:

  Additional arguments passed to specific methods.

## Value

Method-dependent annotation results.
