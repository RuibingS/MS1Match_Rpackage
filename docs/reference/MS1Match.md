# MS1Match Package

Annotates redundant MS1 features in LC-MS untargeted metabolomics
(adducts, isotopes and in-source fragments) by matching them to an MS1
reference library built from pure standards. Features are grouped per
compound and assigned to evidence tiers, optionally supported by MS2
fragment matching. The resulting reference groups can be used to
benchmark feature-grouping tools.
